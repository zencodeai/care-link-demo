# IMP-06 role composition

These factories assemble source components; imports open no listener and load no model. Deployment, host trust and admission are separate actions.

- `core.core_application`: keeps manual/planning/referral ports, installs actor task/draft routes, a sixty-second server-held actor ceiling and the runtime broker. Only Core signs fresh request/task/runtime-bound delegation to Data.
- `data.data_application`: owns business credentials, encrypted tasks/drafts/observations and durable compute occupancy. It installs signed Core task methods plus the inference-only current-context/ledger port. Current identity, consent/scope, sources, controls, channel and runtime fence are rechecked.
- `inference.inference_application`: receives authenticated Data and host-bridge TLS contexts or protected mesh egress sockets for the same authorities. Context, token and proposal checks surround durable slot admission. Tokenization and generation use distinct fixed authenticated host bridge paths. The gateway checks current release authority before delivering output.
- `bridge.bridge_application`: takes the configured artifact directory, model index and private host-owned `lmstudio_token_file` path. It checks fixed loopback REST authentication and authenticates the pinned SDK to the already-loaded model. It verifies the evaluated artifact and render pins before serving. Proofs bind artifact, model, tokenizer, template, window and content. At most two tokenizer operations run. A timeout keeps a still-running tokenizer in its slot.
- `routes.inbound/outbound` defines the fixed role graph. Runtime can reach Core only. Four lease templates admit canonical lowercase UUIDs only; all other paths stay exact. Generation mesh timeouts are forty seconds, with provider deadline at most thirty seconds. `trust.runtime_verifier/current_runtime` consume protected kernel/proxy/fence authority, including the certificate digest.

`ReleaseBindings(None, (), current_false)` disables every AI function. Core and Data remain usable manually; inference/bridge construction refuses unadmitted evidence. A future evaluated binding must supply the exact model manifest and immutable instruction source, source-bound prompt/schema and per-function evidence, plus current release/control authority. A raw name, file hash, model listing or self-declared HTTP field cannot establish that evidence. The checked-in descriptor at config/demo/assistance/model-manifest.json is disabled and contains no fabricated approvals.

The only implemented profile is `worker_summary` / `prepare_summary` / `draft_ready`, and its generated draft is extractive and unsent. `session_read` and exact pinned `protocol_read` are implemented bounded read tools when the catalog is configured. Other typed tools produce bounded safe failures; other functions/bindings remain explicitly unadmitted. Human accept/edit/reject is separate from business communication or consent. A human edit creates a new digest/revision and needs a fresh exact acceptance.

Runtime `RuntimeClient.run_one_turn` performs one explicit authorized task slice, renewing its lease at five-second intervals during one inference. It never automatically retries a model, invokes a model-requested effect, creates tasks or sends communication. Task budgets (four steps, three tools, two proposals) remain at Data across retries and process restarts. Lost ephemeral actor custody requires fresh authenticated revision; it never resets persistent counters. Human waiting ends execution until a fresh actor command. Unknown compute occupies one of two slots until observed completion or independently verified stop/recovery. Zero waiting jobs is an intentional bound below the maximum eight queued: a full system denies optional AI immediately.

Historical session001 did not install an SDK and found the server unavailable. Session003 installs pinned LangGraph1.2.24 and host SDK1.5.0, migrates the current target to `qwen/qwen3.8-27b`, and records actual loaded-model tests separately. It creates no live role/mesh deployment, model load or global AI admission. Human review remains deferred until after IMP-10.

## Scoped workflow and knowledge composition

Use `resources.load_knowledge_resources()` at the trusted composition root. Pass `resources.catalog` to Core and Data and `resources.regions` to Data. This loads the closed local catalog and exact authored CA-XX→CA-ON synthetic scenario binding; it does not fetch publisher URLs. Missing/invalid resources or release catalog mismatch must not admit RAG generation. `ReleaseBindings.knowledge_digest` must be the evaluated catalog digest from current release custody; an arbitrary file hash alone is not evidence. Public patient-independent role lookup remains usable while generation is disabled.

Core queues explicit actor task metadata. `python -m care_link_runtime.worker --ca-file … --cert-file … --key-file …` runs the independently provisioned Runtime using only its broker TLS identity; `--once` performs one poll/graph slice. `tools.imp06_runtime.runtime` exposes the equivalent source factory. Imports do not start listeners. Polling uses fixed `/internal/v1/broker/work`; the workload route graph includes that exact path. No runtime/Data/model credential bypass is provided.

The account/session-bound manual workspace offers an unchecked automatic-preparation opt-in. Standalone `/assistance` keeps explicit preparation and role-scoped knowledge lookup. Polling stops on expiry, access failure or a bounded attempt count. Review separates patient reports and protocol references with publisher metadata and clinical-qualification limits. Accepted drafts remain unsent.

The host `LoadedBinding` resolves an already-loaded SDK handle and verifies exact artifact/template/tokenizer/window/instance identities. It never calls SDK autoload. Bridge composition requires an explicit LM Studio API credential. SDK template controls and REST reasoning controls must agree; empirical capability probes are not a replacement for token proof. Runtime rejects external tracing configuration; raw reasoning is not retained.

See `doc/IMP/slices/IMP-06-bounded-ai-assistance/sessions/003-agentic-workflows-rag/` for architecture/design, framework/resource versions, actual test results and remaining qualification. These factories need explicitly provisioned role-exclusive credentials and current release authority; they do not activate the existing demo deployment.

The worker model-facing schema is a compact evidence-index selection. Gateway code reconstructs full canonical Proposal bindings/text from current sources, rejects duplicate/out-of-scope selections and requires all patient assertions. More than12 mandatory assertions fails preflight before expensive work. Matched nonthinking tokenization uses a pinned SDK internal/generated RPC and vendor keys; changes require fresh compatibility evidence. Session003 preserves the four final passing real-catalog EN/FR/injection cases and prior failed attempts.

Session004 pins LM Studio SDK 1.6.0b1 and verifies authenticated discovery, rendering and generation on LM Studio 0.4.28+2. The credential file must be a regular file owned by the bridge process user with mode 0400 or 0600. Keep it in host-only secret storage. Core, Runtime and Inference accept protected egress sockets for the same fixed authorities as their TLS clients. See the [qualification handoff](../../doc/IMP/slices/IMP-06-bounded-ai-assistance/sessions/004-authenticated-qualification/handoff.md) for tested behavior and remaining deployment requirements.

## Verified release and recovery

`release_custody.ReleaseCustody` persists a signed exact candidate under a monotonic epoch. Evaluator identities are Core, Data, Runtime, Inference and host inference bridge. Each evaluator verifies its local observation and signs an acknowledgment of the candidate digest, current control epoch, activation and process boot. A new boot, expiry, rejected acknowledgment or restrictive epoch invalidates existing bindings. The writer owns the ledger directory and database. Evaluators get narrowly scoped read access. At the trusted composition root, pass `serving_bindings` into the role factories only after the separately signed, current human approval and the evaluator acknowledgments have been verified. Disposable probes use `qualification_bindings` and qualification-only keys and targets.

The evaluated worker summary admits at most 2,048 exact input tokens below the loaded 8,192-token combined budget. The gateway returns `reduce_scope_required` before allocating compute when the exact render exceeds the signed function limit. Current source labels and attribution are preserved.

Data accepts `ProviderStopAuthority` with a host attestation public key, protected receipt directory and independently authenticated fence lookup. The host signer attests observed process exit after the sole inference route was fenced. Assign a new bridge generation on every recovered provider instance. Data reconciles at most the two durable slots, releases only covered prior-generation jobs, and discards a late draft from a retired generation. Real deployment must provision the host signer and fence; broker and model routes have no recovery command.
