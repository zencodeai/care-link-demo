# IMP-04 synthetic candidates

`directory-fixtures.json` contains seven operating-state examples and signed exact engineering admission envelopes. The bilingual qualifications are engineering candidates; no independent human review is claimed. Each envelope explicitly retains `human_review:false` and `participant_admission:false`. Signatures establish the exact authorized engineering source binding, never human review or clinical validity. Source admission remains separate from operating availability and executable destinations.

`directory-source-key-pin.json` is the separate trusted public-key pin candidate. The composition root must supply its trusted key ring independently of feed envelopes. Never learn a key from a submitted feed, accept an envelope-provided key, or replace the trusted pin to make rejected source bytes pass. The fixture private signing key was used only during generation and was not saved. Runtime fixture mutation therefore cannot silently generate a replacement admitted source.

`VerifiedDirectoryAdmission(envelopes, trusted_keys)` verifies Ed25519 signatures over canonical envelope bytes excluding `signature`, with exact version, synthetic tags, source scope and manifest hash. The signed `artifact_digest` is the exact registry key; signed `manifest.payload_digest` binds canonical `{service_id,facts,sources}`. The registry validates each exact source ID/revision/digest tuple, source owner/method, supported needs, complete field freshness coverage and event-specific verification status. Detached map copies prevent caller mutation from changing verified admission state. Missing, unknown-key, forged, mutated, duplicate or incomplete envelopes fail closed.

All sources have fixed observed times and naturally become stale after their applicable freshness window. Re-verification requires new signed exact artifacts and source revisions; changing the clock or replacing a timestamp is not evidence of current verification. These candidates are not loaded into a running lab by this implementation task.
