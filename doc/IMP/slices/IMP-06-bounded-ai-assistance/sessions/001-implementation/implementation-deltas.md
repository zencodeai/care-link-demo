# Implementation scope and compatibility

Canonical stage/task/operation allocations and LLD design sources remain unchanged. Additive generated transport contracts provide function status, current task/draft discovery and exact source-review facts; browser input cannot create authority.

The first implemented profile is worker_summary / prepare_summary / draft_ready with current session assertions, explicit unknown/disputed source labels, source-extractive proposals and unsent human review. Other function/binding profiles are disabled and remain scope, not successful stubs. Draft edits need a new exact acceptance; old task revisions/fences/current-draft identities cannot authorize an old draft.

PostgreSQL task, draft, observation and idempotency bodies are encrypted; lifecycle copies and session dependencies are registered. Actor/certificate/runtime identities are separated. Server actor ceilings expire within sixty seconds and are not persisted across process restart. An explicit fresh human task revision can resume while preserving every persistent task counter and the original deadline. Runtime cannot extend human waiting by claiming another lease.

Compute uses two durable slots and zero waiting jobs (within the specified queue maximum eight). Timeout or cancellation never clears occupancy. Observed completion can clear a slot without releasing a stale result. Verified stop/recovery is absent from model/runtime HTTP tools and defaults denied. A thirty-second inference has separately renewed ten-second step leases; failure to renew fences the output.

A host-only SDK handle adapter performs real template application/tokenization only when an actual verified handle is provided. Inference accesses it through the authenticated fixed host bridge; no SDK/model bypass, character estimate or automatic SDK installation exists. Actual runtime bindings and evidence remain unavailable; no real function is admitted.

The trust adapter adds protected certificate-digest metadata, four narrowly matched UUID lease routes and forty-second mesh timeouts for the three generation transport operations. This modifies source builders only; existing running lab configurations and host trust were not changed. Deployed network containment, model quality/capacity and runtime latency remain unqualified.

The full source lane initially exposed empty editable packages built before new modules existed. Rebuilding those local packages fixed collection; the runner now retains all workspace packages with --all-packages. Captured failed attempts remain history. A later independent review found task-revision review, predicate, auth privacy, runtime fence and mesh routing defects; corresponding regression fixes are recorded in the handoff. No authority controls were waived.
