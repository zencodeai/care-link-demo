# IMP-05 process binding

`python -m tools.imp05_runtime --config /absolute/role/config.json` serves one separately provisioned role. It does not prepare accounts, databases, keys, mesh, policy approvals, host trust or a deployment. The source is opt-in (`referral_enabled: true`, session `imp05-001`); existing IMP-03/04 configurations remain on their current routes.

Core uses `HttpReferralGateway` for signed data calls and `HttpReceiverGateway` for receiver humans. Data uses `HttpReceiverPort`. Receiver has its own PostgreSQL credentials and AES-GCM content key, Core/identity verification keys, and fixed `actor_services` assignment. Receiver obtains only `resolve/current` identity methods; it has no consent-proof or recovery route. Workload verification requires protected Unix socket custody and exact Core/Data/Receiver path rules. No header supplies a workload or human role.

Core/Data/Receiver require `simulator_mapping_file` and `simulator_trusted_keys` (`key_id` to public PEM file). The mapping contains exactly key_id, signature (standard canonical base64 Ed25519), positive integer revision, fixed HTTPS origin, unique service_ids (1–100 canonical UUIDs), workload_id `spiffe://care-link.demo/demo/receiver`, and tags `{environment: demo, population: synthetic}`. Sign canonical sorted compact UTF-8 JSON without signature. Technical signing is configuration integrity, never consent or human approval. Directory/source content has no executable address. Each outbound mesh target must have the same origin and pinned receiver workload identity.

Receiver configuration supports only `normal`, `drop_after_store`, `timeout_before_store`, `unavailable` scenarios. These are explicit synthetic process fixtures; there is no public scenario mutation endpoint or real connector. The worker separately enqueues and sends pending work. Restarted attempted/unknown work reconciles by original dispatch ID and never silently retransmits. `not_found` and unavailable remain reconciliation-needed; this version deliberately has no automatic reauthorization/resend path.
