## Historical reference resolution

Frozen records contain original repository-relative paths and hashes; archived Markdown can also contain relative links from its former location. They intentionally keep the wording/paths as recorded. [relocations.json](relocations.json) maps each moved or replaced original path plus SHA256 to its byte-identical retained file. For a JSON reference, use the original path if its bytes still match; otherwise look up that exact path/hash pair in the map. Do not substitute a newer packet at the same old path.

Earlier correction folders also retain `historical-reference-map.json` files for superseded candidates. Those maps continue to resolve earlier bytes. No acceptance receipt, candidate digest, source file, runtime configuration or test result was regenerated by this reorganization.
